# 🏃 특수체육(APA) 프로그램 제안 전문가 앱

특수체육 비전공자를 위한 AI 기반 프로그램 구성 지원 시스템

## 📋 프로젝트 소개

이 프로젝트는 특수체육(Adapted Physical Activity) 분야의 비전공자들이 장애 학생들을 위한 체육 프로그램을 효과적으로 구성할 수 있도록 돕는 전문가 앱입니다.

직관적인 웹 인터페이스를 통해:
- ❓ **Q&A 시스템**: 특수체육 관련 질문에 즉각 답변
- 📝 **프로그램 자동 생성**: 맞춤형 프로그램 제안서 생성
- 📚 **지식 베이스**: 핵심 개념과 교수 전략 제공
- 💡 **실무 가이드**: 상황별 가이드라인과 팁

## 🚀 빠른 시작

### 1. 의존성 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 앱 실행

**Linux/macOS:**
```bash
chmod +x run_app.sh
./run_app.sh
```

**Windows:**
```cmd
run_app.bat
```

**또는 직접 실행:**
```bash
streamlit run apa_expert_app.py
```

### 3. 브라우저에서 접속
`http://localhost:8501`

## ✨ 주요 기능

- **Q&A 시스템**: 특수체육 관련 질문과 답변
- **프로그램 생성기**: 자동 제안서 생성 및 다운로드
- **지식 베이스**: 체계적인 특수체육 정보 제공
- **가이드**: 장애 유형별 고려사항, 안전 관리 등

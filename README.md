# 🎵 음악 임팩트 컨트롤러 (Music Impact Controller)

좌우 음향 조절을 통한 음악의 임팩트 조절 어플 - 좋아하는 음악을 더 즐겁게 만드는 웹 앱

## ✨ 주요 기능

### 🎚️ 좌우 음향 조절 (Stereo Panning)
- **실시간 좌우 밸런스 조절**: 음악을 왼쪽 또는 오른쪽으로 패닝하여 독특한 청취 경험 제공
- **시각적 피드백**: 좌우 밸런스를 실시간으로 확인할 수 있는 시각적 인디케이터
- **정밀한 조절**: CENTER, LEFT, RIGHT 상태를 정확하게 표시

### 🎛️ 음향 효과 컨트롤

1. **저음 강화 (Bass Boost)**
   - 0-20dB 범위의 저음 증폭
   - 힙합, EDM 등 저음이 중요한 음악에 최적

2. **고음 조절 (Treble Control)**
   - -12dB ~ +12dB 범위의 고음 조절
   - 보컬과 악기의 선명도 조절

3. **리버브 (Reverb)**
   - 0-100% 범위의 공간감 효과
   - 콘서트홀에서 듣는 듯한 느낌

4. **3D 공간감 (Spatial Effect)**
   - 스테레오 이미지 확장
   - 더 넓고 입체적인 사운드

### 🎨 프리셋

빠른 설정을 위한 5가지 프리셋:

- **🔄 리셋**: 모든 설정을 기본값으로
- **🔊 베이스 부스트**: 강력한 저음 강조
- **🎤 보컬 강조**: 보컬이 돋보이는 설정
- **🎭 콘서트홀**: 라이브 공연장 느낌
- **⚡ 다이나믹**: 균형 잡힌 강렬한 사운드

### 📊 실시간 비주얼라이저
- 음악의 주파수를 실시간으로 시각화
- 그라디언트 바 차트로 아름다운 표현

## 🚀 사용 방법

### 1. 앱 실행
브라우저에서 `index.html` 파일을 엽니다.

```bash
# 간단한 HTTP 서버로 실행 (선택사항)
python -m http.server 8000
# 또는
npx http-server
```

브라우저에서 `http://localhost:8000` 접속

### 2. 음악 파일 업로드
1. 중앙의 업로드 영역을 클릭
2. MP3, WAV, OGG 등의 음악 파일 선택
3. 자동으로 재생 시작

### 3. 음향 효과 조절

#### 좌우 음향 조절
- 슬라이더를 좌우로 드래그
- 왼쪽으로 이동: 왼쪽 스피커 강조
- 오른쪽으로 이동: 오른쪽 스피커 강조
- 중앙: 균형잡힌 스테레오

#### 음향 효과
- 각 슬라이더를 조절하여 원하는 사운드 생성
- 실시간으로 변화를 들으며 미세 조정 가능

#### 프리셋 활용
- 하단의 프리셋 버튼 클릭
- 원하는 분위기에 맞는 설정 즉시 적용
- 프리셋 적용 후 추가 조정 가능

## 🎯 사용 예시

### 힙합/EDM 감상
1. "베이스 부스트" 프리셋 선택
2. 저음 강화를 20dB까지 올림
3. 리버브를 약간 추가 (10-20%)

### 발라드/보컬 중심 음악
1. "보컬 강조" 프리셋 선택
2. 고음을 +6dB로 조절
3. 리버브 25%로 공간감 추가

### 클래식/오케스트라
1. "콘서트홀" 프리셋 선택
2. 공간감 70%로 설정
3. 리버브 60%로 넓은 공간 표현

### 실험적 청취
1. 좌우 음향을 극단적으로 한쪽으로 이동
2. 다양한 효과를 극대화
3. 평소와 다른 새로운 음악 경험

## 🛠️ 기술 스택

- **HTML5**: 구조
- **CSS3**: 현대적인 UI 디자인
  - Flexbox 레이아웃
  - 그라디언트 및 애니메이션
  - 반응형 디자인

- **JavaScript (ES6+)**: 핵심 기능
  - Web Audio API
  - Canvas API (비주얼라이저)
  - 객체 지향 프로그래밍

### Web Audio API 노드 구조

```
Audio Source
    ↓
Bass Filter (Low-shelf)
    ↓
Treble Filter (High-shelf)
    ↓
Stereo Panner
    ↓
Analyser (비주얼라이저)
    ↓
Gain Node (볼륨)
    ├─→ Dry Gain → Destination
    └─→ Convolver (Reverb) → Wet Gain → Destination
```

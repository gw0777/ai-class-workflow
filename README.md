# ai-class-workflow

## 프로젝트 개요
AI 수업 워크플로우 및 체육 교육 관련 자료 저장소

## 포함된 도구

### 🏆 실시간 토너먼트 대진표 프로그램
단일 엘리미네이션 방식의 토너먼트 대진표를 생성하고 관리할 수 있는 웹 기반 프로그램

**파일**: `tournament-bracket.html`
**설명서**: `TOURNAMENT_README.md`

#### 주요 기능:
- 참가자 관리 (추가/삭제)
- 자동 대진표 생성
- 실시간 결과 업데이트
- 우승자 자동 표시
- 결과 내보내기

**사용 방법**: 웹 브라우저로 `tournament-bracket.html` 파일을 열어서 바로 사용

## 교육 자료
- 직접교수 및 개별화 지도모형 자료
- 협동학습 및 스포츠 교육 모형 자료
- 여주쌀태권도 제안서

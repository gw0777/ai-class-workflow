# ai-class-workflow

AI 기반 작업 흐름과 교육과정 공동설계 구조를 함께 관리하는 저장소입니다.

## 교육과정 공동설계 에이전트

특수교육교육과정론 15주 패키지의 수업 운영성을 높이기 위해 다음 3단 구조를 추가했습니다.

- 수업 공동설계자: 180분 수업 설계안과 선택지 제안
- 수업 제작자: 승인된 설계를 PPT·실습지·사례·평가자료로 구현
- 독립 검수관: 근거·운영성·특수교육적 적합성 검수

상세 구조: [agent_system/README.md](agent_system/README.md)

프로토콜: [agent_system/protocol.yaml](agent_system/protocol.yaml)

이 구조는 외부 Hermes 런타임에 종속되지 않고, 전문 에이전트 분업·공유 상태·사람 승인 게이트·감사 가능한 결정 로그·제한 재시도·검수 회귀 원칙을 교육 설계에 적용합니다.

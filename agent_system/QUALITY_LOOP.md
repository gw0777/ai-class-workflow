# 품질관리 반복 루프와 상위 에이전트 검수 기록

- 적용 대상: `특수교육교육과정론_15주패키지`
- 적용 구조: EDU-DESIGNER → EDU-PRODUCER → EDU-QA → Loop Station → EDU-LEAD
- 기록 목적: 한 번의 점수 산출로 완료를 선언하지 않고, 결함 수정과 상위 검수를 반복하기 위함
- 현재 상태: `LOOP_STATION`

## 현재 정직한 평가

| 항목 | 현재 점수 | 판정 |
|---|---:|---|
| 구조·형식 | 100/100 | 통과 |
| 실제 180분 운영성 | 72/100 | 확장 필요 |
| 전체 상태 | - | READY 아님 |
| 운영성 목표 | 90/100 이상 | 미달 |
| 주차별 목표 | 80/100 이상 | 주차별 재검수 필요 |

현재 자료는 파일 구조와 형식은 안정적이지만, 매 주차의 사례 분석·학생 산출물·피드백·차별화 지원을 실제 180분 운영 수준으로 강화해야 합니다.

## Loop Station 반복 절차

| 반복 순서 | 검수 패스 | 핵심 질문 | 실패 시 |
|---:|---|---|---|
| 1 | Preflight | 파일이 열리고 필수 산출물이 모두 있는가? | 제작 단계 |
| 2 | Evidence | 성취기준·법령·사례·통계 근거가 정확한가? | 설계 또는 자료 확인 |
| 3 | Pedagogy | 목표·활동·산출물·평가가 연결되는가? | 공동설계 단계 |
| 4 | Operation | 학생이 180분 동안 실제로 수행할 일이 충분한가? | 공동설계 단계 |
| 5 | Render | PPT·실습지의 배치와 사용성이 정상인가? | 제작 단계 |
| 6 | Upper Review | QA 점수와 결함 종료를 상위 관점에서 재검토했는가? | 루프 재실행 또는 차단 |

## 상위 검수관 EDU-LEAD의 역할

EDU-LEAD는 자료를 직접 수정하지 않습니다. 다음 사항을 다시 확인하고 최종 결정을 기록합니다.

- QA 검수 근거가 파일·슬라이드·페이지 위치와 연결되는가?
- 점수가 실제 결함 목록과 일치하는가?
- 이전 루프에서 지적된 결함이 실제로 닫혔는가?
- 같은 결함이 반복되어 점수만 조정된 것은 아닌가?
- 구조 점수와 운영 점수가 혼동되지 않았는가?
- 교수자 승인 기록이 존재하는가?
- 치명적 결함과 미확인 근거가 없는가?

## 루프 기록 양식

각 주차마다 다음 기록을 남깁니다.

```yaml
week: W01
cycle_number: 1
pass_results:
  preflight: PASS
  evidence: PASS
  pedagogy: NEEDS_REVISION
  operation: NEEDS_REVISION
  render: PASS
changed_files: []
remaining_defects:
  - id: W01-OP-001
    severity: Major
    location: ""
    description: ""
next_transition: PROPOSAL
lead_review: PENDING
```

## 완료·차단 기준

### READY

다음 조건을 모두 만족해야 합니다.

- 구조·형식 98점 이상
- 전체 운영성 90점 이상
- 모든 주차 운영성 80점 이상
- Critical 결함 0개
- 근거 미확인 0개
- 교수자 승인 기록 존재
- EDU-QA와 EDU-LEAD의 검수 기록 존재

### BLOCKED

다음 중 하나라도 해당하면 완료를 선언하지 않고 교수자에게 판단을 요청합니다.

- 최대 2회 루프 후에도 같은 Major 결함이 남음
- 법령·성취기준·통계의 근거가 확인되지 않음
- 파일이 열리지 않거나 렌더링 검수가 불가능함
- 180분 수업을 채울 학습자 활동이 부족함
- 개인정보·비공개 자료가 포함될 위험이 있음

## 운영 명령

1. EDU-DESIGNER가 주차별 결손을 제안한다.
2. 교수자가 설계안을 승인한다.
3. EDU-PRODUCER가 자료를 제작한다.
4. EDU-QA가 5개 패스를 수행한다.
5. Loop Station이 결함에 따라 설계 또는 제작으로 회귀시킨다.
6. EDU-LEAD가 최종 검수한다.
7. 기준 미달이면 최대 2회까지 반복한다.
8. 그래도 미달이면 `BLOCKED`로 기록하고 교수자에게 보고한다.

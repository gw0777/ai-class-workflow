# 교육과정 공동설계 에이전트 시스템

특수교육교육과정론과 같은 15주 강의를 실제 180분 수업으로 발전시키기 위한 3단 에이전트 구조입니다.

## 목표

에이전트가 자료를 단순히 생성하는 데서 멈추지 않고 다음을 수행하도록 합니다.

- 교수자의 교육적 의도를 수업 설계안으로 번역한다.
- 승인된 설계안을 PPT·실습지·사례자료로 구현한다.
- 독립 검수로 근거·운영성·특수교육적 적합성을 확인한다.
- 부족한 경우 자동 완료를 선언하지 않고 설계 단계로 회귀한다.

## 3단 구조

| 단계 | 에이전트 | 핵심 질문 | 산출물 |
|---|---|---|---|
| 1 | 수업 공동설계자 | 이 주차를 180분 동안 어떻게 학습하게 할 것인가? | 수업 설계 제안서 |
| 2 | 수업 제작자 | 승인된 설계를 어떤 파일과 활동으로 구현할 것인가? | PPT·실습지·사례·평가자료 |
| 3 | 검수관 | 실제 수업에서 작동하고 근거가 정확한가? | 검수보고서·점수·수정요청 |

교수자는 최종 승인자입니다. 에이전트는 설계안을 제안할 수 있지만, 교육 방향을 임의로 확정하지 않습니다.

## 승인 게이트

1. `INTAKE`: 과목, 주차, 학습자, 수업시간, 현재 파일을 확인한다.
2. `PROPOSAL`: 공동설계자가 설계안과 선택지를 제출한다.
3. `HUMAN_REVIEW`: 교수자가 승인·수정·보류 중 하나를 결정한다.
4. `BUILD`: 제작자가 승인된 설계만 구현한다.
5. `QA`: 검수관이 독립적으로 평가한다.
6. `REVISION`: 기준 미달이면 제작 또는 설계 단계로 회귀한다.
7. `READY`: 구조 점수 98점 이상, 운영 점수 90점 이상, 주차별 80점 이상, 치명적 결함 0일 때만 완료한다.

## 운영 원칙

- 제안과 실행을 분리한다.
- 근거 없는 교육적 주장을 사실처럼 쓰지 않는다.
- 교수자 승인을 받기 전에는 파일을 덮어쓰지 않는다.
- 검수관은 제작자와 다른 관점으로 평가한다.
- 모든 점수에는 근거 파일, 페이지·슬라이드·활동 위치를 기록한다.
- 학생 산출물과 피드백 방법이 없는 수업은 180분 수업으로 간주하지 않는다.
- 개인정보·비공개 파일·API 키는 산출물과 로그에 포함하지 않는다.

## Hermes-inspired 채택 항목

이 프로젝트는 외부 Hermes 런타임을 복사하거나 종속성으로 추가하지 않고, 교육 설계에 유효한 운영 패턴만 채택합니다.

- 전문 에이전트 프로필과 제한된 도구 권한
- 공유 작업판에 의한 상태 관리
- 제안·승인·실행·검수의 명시적 단계
- 도구 호출 및 결정의 감사 가능한 기록
- 실패 시 무한 반복하지 않는 제한 재시도
- 검수 결과에 따른 이전 단계 회귀
- 반복 가능한 수업 설계 산출물 템플릿

## 현재 적용 대상

1차 적용 대상은 `특수교육교육과정론_15주패키지`입니다. 현재 구조·형식은 강점이지만 실제 3시간 운영성은 확장이 필요하므로, 각 주차에 사례·활동·산출물·피드백을 보강하는 것을 우선순위로 둡니다.

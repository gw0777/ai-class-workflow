## 상위 검수 판정

이번 보강은 PPT 장수나 파일 개수를 늘리는 작업이 아니라 다음 운영 결손을 보완하는 작업입니다.

- 학생이 모둠 안에서 실제 역할을 갖도록 함
- 지체장애·자폐성장애를 고려한 설계 선택지 추가
- 수업 전 출발점과 수업 후 변화를 확인
- 교수자가 실제로 사용할 수 있는 진행 문장 제공
- 실제 사례와 구성 사례를 구분하고 검증 양식을 남김

## 남은 검증

실제 현장사례 1건 이상을 출처·동의·비식별화까지 확인하기 전에는 100점을 부여하지 않습니다. 또한 W01을 시범 운영하여 시간 초과·미달, 학생 반응, 접근성 문제를 기록해야 `READY`로 전환할 수 있습니다.

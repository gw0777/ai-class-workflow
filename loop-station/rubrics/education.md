# 루브릭: 교육/수업 자료 (education)

공통 규칙은 `_common.md`를 따른다. 5개 카테고리 × 20점 = 100점.

## 1. 정확성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 사실/개념 정확성 | 교과 내용·이론·모형 설명이 정확한가 |
| 용어 일관성 | 교육 용어가 문서 전체에서 일관되게 사용되는가 |
| 수치·인용 검증 | 차시·시간·인원 등 수치와 출처 표기가 맞는가 |
| 오탈자 없음 | 맞춤법·띄어쓰기 오류가 없는가 |

## 2. 구조·완결성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 학습목표 명시 | 관찰 가능한 행동 동사로 학습목표가 제시되는가 |
| 도입-전개-정리 구조 | 수업 흐름이 단계별로 완결적으로 구성되는가 |
| 요구사항 전부 반영 | 사용자가 요청한 요소가 모두 포함되는가 |
| 분량 적정 | 수업 시간·학습자 수준 대비 분량이 적절한가 |

## 3. 명료성·대상 적합성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 학습자 수준 적합 | 어휘·활동 난이도가 대상 학년/수준에 맞는가 |
| 문장 명료성 | 지시·설명 문장이 한 번에 이해되는가 |
| 예시 적절성 | 예시·시범이 목표와 직접 연결되는가 |
| 지시문 실행 가능성 | 교사/학생이 그대로 따라 할 수 있는가 |

## 4. 형식·표현 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 서식 일관성 | 제목·표·번호 체계가 일관적인가 |
| 시각 요소 품질 | 표·아이콘·배치가 내용 이해를 돕는가 |
| 한국어 어문 규범 | 문어체·경어 등 문체가 규범에 맞는가 |
| 접근성 (HTML인 경우) | 대비·글자 크기·구조화된 마크업이 적절한가 (비HTML이면 인쇄 가독성) |

## 5. 실용성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 즉시 사용 가능성 | 추가 편집 없이 현장 투입 가능한가 |
| 확장/재사용 용이성 | 다른 차시·학급에 변형 적용이 쉬운가 |
| 평가/활동 연계 | 평가 기준 또는 활동지가 목표와 연계되는가 |
| 맥락 적합성 | 학교급·교육과정 맥락에 부합하는가 |

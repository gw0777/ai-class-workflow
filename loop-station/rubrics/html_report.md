# 루브릭: HTML 보고서/페이지 (html_report)

공통 규칙은 `_common.md`를 따른다. 5개 카테고리 × 20점 = 100점.

## 1. 정확성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 내용 정확성 | 보고 내용·데이터·주장이 사실과 일치하는가 |
| 데이터 일관성 | 본문·표·요약 간 수치가 서로 일치하는가 |
| 마크업 유효성 | 태그 중첩·닫힘 등 구조 오류가 없는가 |
| 오탈자 없음 | 맞춤법·띄어쓰기 오류가 없는가 |

## 2. 구조·완결성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 문서 구조 | 제목 계층(h1~h3)·섹션 구성이 논리적인가 |
| 요구사항 전부 반영 | 요청된 섹션·정보가 모두 포함되는가 |
| 자체 완결성 | 외부 CDN·폰트·스크립트 없이 단일 파일로 동작하는가 |
| 핵심 요약 제공 | 결론/요약이 앞부분에서 파악되는가 |

## 3. 명료성·가독성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 문장 명료성 | 문장이 간결하고 한 번에 이해되는가 |
| 정보 위계 | 중요 정보가 시각적으로 우선 배치되는가 |
| 표·시각 요소 | 표/그래프가 본문 이해를 실제로 돕는가 |
| 전문용어 처리 | 필요한 용어에 설명이 붙는가 |

## 4. 기술 품질 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 렌더링 정상 | 브라우저에서 깨짐 없이 표시되는가 |
| 반응형 | 좁은 화면에서 가로 스크롤 없이 읽히는가 |
| 라이트/다크 모드 | `prefers-color-scheme` 대응이 되는가 |
| 접근성 | `lang="ko"`, 대비, 시맨틱 태그가 적절한가 |

## 5. 실용성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 즉시 사용 가능성 | 그대로 공유/게시 가능한가 |
| 인쇄 적합성 | 인쇄 시에도 읽을 수 있는가 |
| 유지보수 용이성 | 내용 갱신이 쉬운 구조인가 |
| 목적 부합 | 보고 대상·목적에 맞는 어조와 깊이인가 |

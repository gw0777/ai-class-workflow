# 루브릭: 범용 산출물 (general)

공통 규칙은 `_common.md`를 따른다. 5개 카테고리 × 20점 = 100점.
(education / html_report / document 에 해당하지 않는 모든 산출물의 기본 루브릭)

## 1. 정확성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 사실/내용 정확성 | 내용·데이터·주장이 사실과 일치하는가 |
| 용어·표기 일관성 | 용어와 표기가 문서 전체에서 일관적인가 |
| 내부 일관성 | 본문 내 수치·설명이 서로 모순되지 않는가 |
| 오탈자 없음 | 맞춤법·띄어쓰기 오류가 없는가 |

## 2. 구조·완결성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 논리적 구조 | 도입-본론-결론 등 흐름이 논리적인가 |
| 요구사항 전부 반영 | 사용자가 요청한 요소가 모두 포함되는가 |
| 자체 완결성 | 외부 자료 없이 그 자체로 이해·사용 가능한가 |
| 분량 적정 | 목적 대비 과부족 없는 분량인가 |

## 3. 명료성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 문장 명료성 | 문장이 간결하고 한 번에 이해되는가 |
| 대상 적합성 | 독자/사용자 수준에 맞는 어휘·설명인가 |
| 정보 위계 | 중요 정보가 우선 배치되는가 |
| 예시·근거 | 주장에 적절한 예시·근거가 붙는가 |

## 4. 형식·표현 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 서식 일관성 | 제목·표·번호 체계가 일관적인가 |
| 시각 요소 품질 | 표·시각 요소가 이해를 돕는가 |
| 한국어 어문 규범 | 문체가 어문 규범에 맞는가 |
| 매체 적합성 | 산출 형식(HTML/문서 등)의 관례를 지키는가 |

## 5. 실용성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 즉시 사용 가능성 | 추가 작업 없이 바로 사용 가능한가 |
| 재사용 용이성 | 변형·확장 적용이 쉬운가 |
| 목적 부합 | 요청의 본래 목적을 달성하는가 |
| 맥락 적합성 | 사용 상황·환경에 부합하는가 |

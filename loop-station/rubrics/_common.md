# 공통 채점 규칙 (_common.md)

모든 유형 루브릭에 공통 적용되는 규칙. 유형별 루브릭(`education.md`, `html_report.md`, `document.md`, `general.md`)과 함께 읽는다.

## 1. 점수 구조

- 5개 카테고리 × 20점 = **100점 만점**
- 각 카테고리는 4개 하위 항목 × 5점
- 회전(iteration) 총점 = 20개 하위 항목 점수의 합 (이것이 정본이며, 감점 목록은 설명 자료)

## 2. 감점표 (결함 등급)

| 등급 | 감점 | 해당 항목 점수 | 예시 |
|---|---|---|---|
| 치명 (critical) | −5 | 해당 하위 항목 0점 | 사실 오류, 요구사항 누락, HTML 렌더링 실패, 수신자/대상 오류 |
| 중대 (major) | −3 | 해당 하위 항목 ≤2점 | 구조 결함, 대상(학습자/수신자) 부적합, 논리 비약, 접근성 결여 |
| 경미 (minor) | −1 | 해당 하위 항목 ≥4점 | 오탈자, 서식 불일치, 어색한 문장 |

감점은 결함이 발견된 하위 항목에 귀속시키고, 감점 목록에 등급·위치·사유·수정 지시를 기록한다.

## 3. 게이트 (통과 조건)

**98/100점 이상 + 앵커 규칙 충족** 시에만 통과(pass).

> **앵커 규칙**: 마지막 회전 기준 **치명 0건 + 중대 0건 + 경미 최대 2건**.
> 총점이 98 이상이어도 앵커 규칙을 만족하지 못하면 재작업(revise)이다.

## 4. 채점 무결성 (필수)

1. 감점 우선: 결함을 먼저 찾고, 결함 없음이 확인된 항목만 만점.
2. **회전 1은 상한 95점 + 개선점 3건 이상 필수 도출.**
3. 모든 항목에 코멘트 필수 (만점 항목도 확인 내용 기재).
4. 재채점 시 이전 감점 각각의 해소 여부를 명시.
5. 최대 5회전. 미통과 중단 시 잔여 결함 보고.

## 5. 채점 출력 형식 (고정)

```
[회전 N 채점]
| 카테고리 | 하위 항목 | 점수/5 | 코멘트 |
... 20행 ...

감점 목록:
- (등급, −점수) 위치 — 사유 → 수정 지시

총점: NN/100
판정: 통과 | 재작업
```

이 표의 내용이 그대로 기록 JSON의 `iterations[].criteria` / `iterations[].deductions`가 된다.

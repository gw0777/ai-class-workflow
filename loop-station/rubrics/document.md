# 루브릭: 이메일/업무 문서 (document)

공통 규칙은 `_common.md`를 따른다. 5개 카테고리 × 20점 = 100점.
(이메일, 공문, 제안서, 안내문, 회의록 등 업무 문서에 적용)

## 1. 정확성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 사실 정확성 | 날짜·이름·수치·직함 등이 정확한가 |
| 수신자/대상 정확성 | 수신자·참조·호칭이 올바른가 |
| 일정·조건 일관성 | 본문 내 일정/조건이 서로 모순되지 않는가 |
| 오탈자 없음 | 맞춤법·띄어쓰기 오류가 없는가 |

## 2. 구조·완결성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 용건 선명성 | 첫 문단에서 용건이 파악되는가 |
| 필수 요소 포함 | 인사·본문·요청/기한·맺음·서명 등 형식 요소가 갖춰졌는가 |
| 요구사항 전부 반영 | 요청된 내용이 모두 포함되는가 |
| 분량 적정 | 용건 대비 과부족 없는 분량인가 |

## 3. 명료성·어조 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 문장 명료성 | 한 문장 한 용건, 모호함 없는가 |
| 어조 적합성 | 수신자와의 관계·상황에 맞는 경어/격식인가 |
| 요청 명확성 | 상대가 해야 할 행동과 기한이 명확한가 |
| 부담 최소화 | 불필요한 수식·중복이 없는가 |

## 4. 형식·표현 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 서식 일관성 | 제목·번호·들여쓰기 체계가 일관적인가 |
| 제목(제목줄) 품질 | 제목만으로 내용이 예측되는가 |
| 한국어 어문 규범 | 공문서/비즈니스 문체 규범에 맞는가 |
| 첨부·참조 처리 | 첨부 언급·링크·참조 표기가 정확한가 |

## 5. 실용성 (20점)

| 하위 항목 (각 5점) | 확인 내용 |
|---|---|
| 즉시 발송 가능성 | 수정 없이 바로 발송/제출 가능한가 |
| 후속 조치 용이성 | 회신·결재 등 다음 단계가 자연스러운가 |
| 기록 적합성 | 보관·검색 시 맥락이 남는가 |
| 위험 관리 | 오해·책임 소지가 있는 표현이 없는가 |

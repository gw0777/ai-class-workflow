가설

보고서에 옵션 3개 · 고른 이유 · 교훈 반영 기록을 강제하면, 완료 판정(check)만으로 "넓게 보고 골랐는지"와 "지난 교훈을 썼는지"를 확인할 수 있다.

확인 기준: 새 규칙마다 통과·실패 테스트가 있고, 메모리에 없는 교훈을 인용하면 거부된다. 기존 68개 테스트는 그대로 통과해야 한다.

멘탈 시뮬레이션 바꾸면서 돌려 본 것 (실패 포함)

시작 가드를 부작용 없는 함수(plan_run)로 떼어 낸 직후 기존 68개 테스트를 먼저 돌려 동작이 그대로인지 확인했습니다(모두 통과). 그다음 새 필수 항목 min_options를 넣자 예시 명세 2개가 검증에 걸려 테스트 21개가 실패했습니다. 명세에 항목을 추가한 뒤에도 테스트 도구(write_report)가 새 항목을 몰라 5개가 남았습니다. 둘 다 코드 결함이 아니라 새 규칙에 맞춰 갱신할 부분이었고, 고친 뒤 82개 모두 통과를 확인했습니다.

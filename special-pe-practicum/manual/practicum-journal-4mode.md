# 네 칸 실습 일지 — 야생 학습 4모드 양식

> 현장 교육실습 매뉴얼 **⑤ 성찰·평가·피드백**의 성찰일지 템플릿을 확장한 양식이다.
> 책 『2장 에센스 체험』 69쪽의 '야생 학습의 네 가지 모드'를 실습 수업 한 차시에 적용한다.
> 매뉴얼 본문(`practicum-manual.md`, Notion DB와 동기화)은 바꾸지 않고 별도 양식으로 둔다.

## 1. 네 칸과 도는 순서

종이 한 장 가운데에 십자를 긋고, 왼쪽 위부터 시계 방향으로 적는다. 위는 **미래**, 아래는 **과거·현재**, 왼쪽은 **분산(넓게)**, 오른쪽은 **집중(좁게)**이다.

| | 분산 (넓게) | 집중 (좁게) |
|---|---|---|
| **미래** | ① 옵션 — 할 수 있는 방법을 넓게 늘어놓기 | ② 가설 — 하나를 골라 맞고 틀림을 셀 수 있는 문장으로 |
| **과거·현재** | ④ 지도 — 본 것을 한 장으로 모으기 | ③ 액관해 — 실제 수업에서 벌어진 일에 집중해 기록 |

- ② → ③ 사이: **멘탈 시뮬레이션** — 수업 전에 머릿속(또는 지도교사와 말로)으로 먼저 돌려 보기
- ④ → ① 사이: **멘탈 레프리젠테이션** — 지도가 머릿속 지도가 되어 다음 차시의 옵션을 바꾼다

> '액관해'는 책의 정의를 아직 확인하지 못했다. 이 양식에서는 그림 속 자리(과거·현재 × 집중)대로, 실제 수업에서 벌어진 일에 집중해 기록하는 칸으로 쓴다.

## 2. 작성 규칙

| 칸 | 규칙 | 루프 정석의 같은 규칙 |
|---|---|---|
| ① 옵션 | 고르기 전에 **3개 이상** 적고, 각각 왜 후보인지 한 줄 | `options` 3개 이상 |
| ② 가설 | 고른 1개와 고른 이유. **숫자로 확인할 수 있게** 쓴다 (횟수·시간·성공 비율) | `chosen` + 수치 성공 기준 |
| 멘탈 시뮬레이션 | 수업 전 체크 3가지: 안전(매뉴얼 ④), 학생 자리에서 보이는가/들리는가, 안 될 때 대안 | `simulate` |
| ③ 액관해 | **본 사실만** 적는다 (횟수, 시각, 직전 상황). 해석은 ④로 넘긴다 | `start → merge → check` |
| ④ 지도 | 이번 차시에서 알게 된 것 1~3줄 + **다음 차시에 가져갈 교훈 1줄** | 메모리 + 스킬 메모리 |
| 다음 일지 ① | 지난 교훈을 이번 옵션에 **반영했는지** 체크. 반영 안 했으면 이유 | `lessons_applied` / `lessons_skip_reason` |

**개인정보**: 학생은 이니셜이나 번호로 적는다. 장애 진단명·연락처 원문은 일지에 쓰지 않는다 (필요하면 담당 교사 기록부를 참조한다고만 적는다).

## 3. 준비도 단계별로 연습할 칸 (제안)

준비도 컷오프 65/40은 그대로 두고, 단계마다 일지에서 무게를 둘 칸을 정한다.

| 준비도 | 역할 | 일지에서 연습할 칸 |
|---|---|---|
| 0–39점 | 보조·관찰 | ④ 지도 중심. 관찰 사실로 학생의 참여·이탈 패턴을 넓게 적는다 |
| 40–64점 | 공동지도 | ①·②는 지도교사와 **함께** 세우고, ③·④는 직접 쓴다 |
| 65–100점 | 주도지도 | 네 칸을 혼자 한 바퀴. 다음 일지 ①에서 지난 교훈 반영 여부가 확인 지점 |

## 4. 빈 양식 (복사해서 사용)

```
차시: ____  날짜: ____  학생: ____ (이니셜/번호)  준비도: ____점 (보조·관찰 / 공동지도 / 주도지도)

지난 교훈 반영:  [ ] 반영함 → 어떻게: ______________   [ ] 반영 안 함 → 이유: ______________

┌──────────────── 미래 ────────────────┬──────────────────────────────────────┐
│ ① 옵션 (분산) — 3개 이상, 각 이유      │ ② 가설 (집중) — 고른 1개 + 숫자 기준     │
│ 1.                                   │ 고른 것:                              │
│ 2.                                   │ 이유:                                 │
│ 3.                                   │ 확인 기준(숫자):                       │
├──────────── 과거·현재 ────────────────┼──────────────────────────────────────┤
│ ④ 지도 (분산) — 알게 된 것 + 교훈 1줄  │ ③ 액관해 (집중) — 본 사실만             │
│                                      │                                      │
│ 다음 차시 교훈:                        │                                      │
└──────────────────────────────────────┴──────────────────────────────────────┘
멘탈 시뮬레이션 체크:  [ ] 안전 점검  [ ] 학생 자리에서 보임/들림  [ ] 안 될 때 대안: ________
```

## 5. 작성 예시 (가상의 예시 데이터)

```
차시: 3  학생: A (자폐성장애)  준비도: 52점 (공동지도)
지난 교훈 반영: [x] 반영함 → "대기 시간이 길면 자리를 뜬다" → 대기 줄을 2명 이하로 나눔

① 옵션
  1. 시각 단서 카드 — 순서를 보면 따르는 편
  2. 활동 시간 쪼개기 — 집중 시간이 짧음
  3. 또래 도우미 — 친구 행동을 따라 하는 편
② 가설
  고른 것: 1. 시각 단서 카드 (지도교사와 함께 결정)
  이유: 지난 차시에 순서를 보여 주자 2분간 참여함
  확인 기준: 공 던지기 10분 동안 자리 이탈 2회 이하
멘탈 시뮬레이션: [x] 안전 점검 [x] 카드가 학생 자리에서 보임 [x] 대안: 지도교사 손짓 신호
③ 액관해
  자리 이탈 3회 (2분, 6분, 9분). 3회 모두 공을 기다리는 동안.
  카드를 본 직후 1분은 참여함.
④ 지도
  카드는 시작에는 효과가 있지만, 기다리는 시간에는 효과가 사라진다.
  다음 차시 교훈: 기다리는 동안 할 일(공 닦기 등)을 카드에 넣는다.
```

가설(2회 이하)은 틀렸지만(3회), 지도가 자라서 다음 차시 옵션이 바뀐다. 한 바퀴의 목적은 다음 바퀴의 옵션을 더 좋게 만드는 것이다.

---

> ⚠️ 실습 지도·자기개발 참고용이며 공식 평가를 대체하지 않는다. 준비도 단계별 연습 칸은 제안이다.

# 특수체육 시각장애 교재: 훈련·트레이닝 관리와 가이드편

`index.html` 한 파일로 된 카드 학습 교재입니다. 「과학적 코칭 랩 최종 교재」의 코드(왼쪽 고정 차례와 본문 단, 장별 프롬프트 카드, 진도 저장, 복사 버튼, 현재 읽는 장 표시)를 벤치마킹해 시각장애 학생·선수 지도에 맞게 만들었습니다.

## 구성
| 부 | 내용 |
|----|------|
| 1부 훈련·트레이닝 관리 | 시각장애 이해와 등급 · 첫 면담과 안전 선별 · 체력·기능 평가 · 훈련 처방과 주기화 · 훈련 환경과 오리엔테이션 · 지도 언어와 피드백 · 기록 관리와 주간 재설계 · 부록 |
| 2부 가이드편 | 가이드의 다섯 원칙 · 안내 보행 기본 · 가이드 러닝 · 종목별 가이드와 골볼 · 수업 속 또래 가이드 · 체험 수업 설계와 윤리 · 부록 A 가이드 신호 사전 · 부록 B 기준값 표와 참고자료 |
| 수업 자료 | 직접교수 6단계 지도안 3개(안내 보행, 가이드 러닝 입문, 골볼 입문) · 가이드 기술 루브릭 · 출구 카드 |

카드는 세 종류입니다.
- **학습 카드 51장**: 장 끝에서 눌러 답을 보고, 「학습 카드 덱」에서 뒤집기·섞기·「알아요/다시」 표시·장별 묶음으로 복습합니다.
- **과제 카드 12장**: 수업 시간에 몸으로 하는 과제입니다. 성공 기준을 모두 체크하면 「통과」가 표시됩니다(개별화 지도모형의 숙달 기준).
- **프롬프트 카드 15장**: 복사해서 AI에 붙여 넣고, 「좋은 답의 조건」으로 답을 점검합니다(원본 교재와 같은 형식).

예시 선수 세 명(V-07 · V-12 · V-21)은 가상 인물입니다.

## 원본에서 가져온 것과 바꾼 것
| 원본 교재 | 이 교재 |
|-----------|---------|
| 왼쪽 고정 차례, 진도 막대, 장별 「이 장을 끝냈어요」 | 그대로 쓰고, 집계를 1부·2부·수업 자료 세 묶음으로 일반화 |
| 프롬프트 카드(상황 → 프롬프트 → 좋은 답의 조건 → 더 좋게 묻기 → 연습) | 그대로 |
| 주황 강조색 하나 | 점자블록 노랑 하나(바탕 전용, 그 위 글자는 늘 검정). 점형 블록 무늬는 멈춤·안전, 선형 블록 무늬는 가이드·이동 방향 |
| · | 학습 카드 덱, 과제 카드 통과 표시, 글자 크기 3단계, 고대비, 화면 낭독기용 속성(aria), 본문 바로가기 |

## 여는 법
- 브라우저로 `index.html`을 엽니다. 체크한 항목과 학습 카드 기록은 그 브라우저에만 저장됩니다.
- Claude 아티팩트로 올릴 때는 파일 안의 「아티팩트 본문 시작」과 「아티팩트 본문 끝」 주석 사이만 올립니다. 바깥 문서 틀은 게시할 때 자동으로 붙습니다.

## 「확인 필요」 항목
교재를 만들 때 원문을 직접 확인하지 못해 본문에 「확인 필요」로 표시한 값입니다. 수업 전에 원문으로 확인해 주세요. 1부 과제 카드 1-1과 2부 과제 카드 3-1은 학생이 이 값을 원문에서 찾아 채우는 활동입니다.
1. 장애인복지법 시행규칙의 시각장애 「장애의 정도가 심한 장애인」 기준(좋은 눈 교정시력 0.06 이하, 두 눈 시야 각각 모든 방향 5도 이하, 2차 자료 기준)
2. 장애인 등에 대한 특수교육법 시행령의 시각장애 특수교육대상자 선정 기준 문구
3. World Para Athletics 가이드 끈(테더) 길이 규격
4. IBSA 골볼 경기 시간·선수 교체 등 세부 규정(2025년판)

## 검사
저장소 루트에서 실행합니다. 추가 설치가 필요 없습니다.

```bash
python3 -m unittest discover -s special_pe_visual_impairment/tests -v
```

- `tests/test_static.py`: 표준 라이브러리만 씁니다. 태그 짝, id 중복, 내부 링크, 진도 집계, 학습 카드 수, 과제 카드 기준 수, 금지 용어(용어는 「특수체육」으로 통일, README도 함께 검사), 외부 자원, 아티팩트 본문 규칙, 밝은·어두운 테마 색 토큰, 지도안 6단계와 50분 합계, 목표 심박·LogMAR 계산을 검사합니다.
- `tests/test_browser.py`: Node.js용 Playwright가 있으면 `tests/browser_check.cjs`를 실행해 카드 뒤집기, 「알아요/다시」 저장, 키보드 조작, 진도, 과제 카드 통과, 복사 버튼, 글자 크기·고대비, 1280px·390px에서 가로 스크롤 없음, 다크 모드를 확인합니다. 없으면 건너뜁니다.

브라우저 검사만 따로 돌리고 화면을 저장하려면:

```bash
node special_pe_visual_impairment/tests/browser_check.cjs --shots <저장할 폴더>
```

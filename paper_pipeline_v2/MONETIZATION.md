# 수익화 전략 (구독 기반 SaaS)

## 1. 인기 AI/SaaS 앱 10종 수익화 분석

| 앱 | 수익 모델 | 핵심 가치 제안 | 락인(lock-in) 전략 | 가격 구조(대략) |
|-----|-----------|--------------|------------------|------------------|
| **Notion AI** | Freemium + 애드온 구독 | 문서 안에서 바로 쓰기/요약 | 작업공간·문서 데이터 잠금 | 워크스페이스 구독 + AI 애드온 ≈$8~10/월 |
| **ChatGPT Plus** | 구독(정액) | 최신 모델·도구 우선 접근 | 대화이력·커스텀GPT·습관 | $20/월 정액 |
| **GitHub Copilot** | 구독(시트/자치) | IDE 내 자동완성으로 시간절약 | 에디터/워크플로 통합 | $10~19/인·월, Biz 시트 |
| **Perplexity Pro** | Freemium + 구독 | 출처 기반 실시간 답변 | 검색이력·Collections | $20/월 (Pro 검색 횟수·프리미엄 모델) |

| **Copy.ai** | Freemium + 구독 | 세일즈/마케팅 카피 | 워크플로·템플릿 | Free + Pro $36~/월 |
| **Grammarly** | Freemium + 구독 | 실시간 문장 교정 | 브라우저·앱 전역 통합·스타일 | Free + Premium ≈$12~30/월 |
| **Otter.ai** | Freemium + 구독 | 회의 자동 전사/요약 | 회의녹·캘린더·협업 | Free(월 분수 한도) + Pro/Biz |
| **Canva AI** | Freemium + 구독 | 디자인 안 AI 생성(Magic) | 템플릿·브랜드키트·에셋 | Free + Pro ≈$15/월 (AI 크레딧 포함) |

### 공통 성공 패턴
1. **Freemium 깔대기**: 무료에서 가치를 느끼게 하되 "한도"를 걸어 유료 전환을 유도(Perplexity 검색 횟수, Otter 분수, Canva 크레딧).
2. **워크플로 내재화**: 도구가 사용자의 일상 작업 흐름(IDE, 문서, 브라우저) 안에 들어갈수록 이탈이 어렵다(Copilot, Grammarly, Notion).
3. **데이터 락인**: 축적된 산출물·이력·템플릿이 재사용될수록 이탈 비용이 커진다(Midjourney 갤러리, Jasper 브랜드 키트).
4. **변동비 연동 과금**: 생성형 AI는 토큰 비용이 크므로 "사용량 한도·티어"로 마진을 보호(Midjourney Fast시간, ChatGPT 모델 접근).

## 2. paper_pipeline_v2 적용 전략

### 유료화할 기능
- **무제한 논문 초안 생성**(Free는 월 3편 한도) — 핵심 과금 레버.
- **생성 이력 보관 및 재다운로드**(DOCX) — 데이터 락인.
- **우선 처리 큐·고급 모델·긴 컨텍스트** — 상위 티어 차별화.
- **셌프호스트·팀 좌석·SSO** — 기관/연구소(Enterprise).

### 가격 구조
| 플랜 | 가격 | 월 논문 한도 | 핵심 혜택 |
|------|------|------------|----------|
| **Free** | $0 | 3편/월 | DOCX 내보내기, 문헌 수집 |
| **Pro** | $29/월 | 무제한 | 우선 처리, 이력 보관, 이메일 지원 |
| **Enterprise** | 문의 | 무제한 + 팀 | 온프레미스, SSO, 감사로그, SLA |

### 락인 요소
- **데이터**: 생성 이력·참고문헌 라이브러리·논문 버전이 계정에 축적.
- **워크플로**: n8n·MCP 통합으로 연구실 자동화 파이프라인에 난입.
- **통합**: Cursor/Claude 등 MCP 클라이언트, 학과/저널 양식 템플릿.

## 3. 구현된 수익화 인프라 (코드)
- `billing.py`: SQLite 스키마(users/subscriptions/usage_events), 플랜 카탈로그, 사용량 미터링, 월간 한도, Stripe 웹훅.
- `mcp_server.py`: API 키 인증, 사용량 추적 미들웨어, 한도 초과 시 402, `/api/plans`·`/api/usage`·`/api/signup`·`/webhooks/stripe`.
- `tests/test_billing.py`: 한도·업그레이드·강등 단위 테스트.
